# MCP Universal Studio (Desktop Portable EXE)

> Автономная мультиагентная студия оркестрации задач (DAG) с прямой поддержкой протокола **Model Context Protocol (MCP)**, нативным встроенным браузером для чатов (DeepSeek, ChatGPT, Claude) через Electron `<webview>` и прямым управлением Windows / WSL2 через `winremote-mcp`.

---

## 🚀 Быстрый старт на Windows 10/11

### Требования
* **ОС**: Windows 10 / 11 (64-bit)
* **Node.js**: v18+ (для сборки из исходников)
* **winremote-mcp.exe**: локальный сервер MCP на порту `8090` (протокол `2024-11-05`)

---

## 📦 Сборка в Portable EXE

1. Откройте папку проекта в терминале:
   ```cmd
   cd C:\Users\ВЕРА\Desktop\4554
   ```
2. Запустите автоматический скрипт сборки:
   ```cmd
   build-exe.bat
   ```
   *Скрипт автоматически выполнит `npm run build` и упакует приложение через `electron-builder`.*
3. Готовый переносимый исполняемый файл появится в папке:
   ```
   dist-electron\MCP Universal Studio.exe
   ```
   Файл полностью автономен, не требует прав администратора и запускается с любого места или флешки.

## 🛠️ Рабочий сценарий: «Чат-модель ➔ MCP вызов ➔ Результат»

1. **Запустите сервер winremote-mcp**:
   - Дважды кликните по `start-studio.bat` (или запустите `winremote-mcp.exe` на порту `8090`).
2. **Откройте вкладку «Браузер»** в студии:
   - Переключитесь на DeepSeek Chat, ChatGPT или Claude (работают в нативном `<webview>` без блокировок Cloudflare).
3. **Нажмите «Промпт для чата»** в адресной строке:
   - В буфер обмена скопируется готовая системная инструкция со списком инструментов (`Shell`, `FileWrite`, `FileRead`, `FileList`).
4. **Вставьте промпт в диалог с нейросетью**:
   - Попросите модель решить задачу (например: *«Создай скрипт для очистки временных файлов и выполни Get-Date»*).
5. **Нажмите «Ответ в MCP»**:
   - Вставьте JSON-блок или ответ модели. Студия автоматически выполнит команду через `winremote-mcp` и выведет результат в реальном времени.

## 🧩 Основные разделы приложения

* **Оркестратор**: Автономный DAG-планировщик. Архитектор декомпозирует цели, Имплементер вызывает инструменты, Тестировщик верифицирует результат. Встроенная политика безопасности HITL (Human-in-the-Loop) и Self-Healing цикл автоисправления ошибок.
* **Браузер (Webview)**: Мульти-вкладочный интерфейс с изолированными сессиями (`persist:chat-*`), горячей клавишей `Alt+O`, сохранением состояния вкладок в `localStorage` и кнопкой отправки контекста веб-страницы в оркестратор.
* **Ручной тест MCP**: Прямой вызов инструментов через JSON-RPC 2.0 с живой подсветкой результата и временем выполнения.
* **Файлы Workspace**: Двусторонняя синхронизация файлов с реальным диском через `FileList` / `FileWrite`.
* **Пул моделей**: Управление каскадом локальных и удаленных провайдеров (Ollama, Groq, OpenRouter, DeepSeek).
* **Экспериментальное (Demo / Coming Soon)**:
  - GameDev & Skyrim LE Suite (NIF v20.2.0.7, Papyrus, Havok, Unity, Godot, Blender).
  - OpenCode CLI Bridge (генерация `opencode.json`).
  - Gemini AI Hub (мультимодальные модели, Google Search Grounding).
  - 3D Кибер-Арена (симуляция агентной среды Three.js).
